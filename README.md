# pcha-plugins Marketplace

A collection of [Claude Code](https://claude.ai/code) plugins by Pablo Cha.

## Installation

Add this marketplace to Claude Code:

```bash
claude plugin marketplace add https://raw.githubusercontent.com/pcha/plugins-marketplace/main/marketplace.json
```

Then install plugins:

```bash
claude plugin install android-claude-plugin
```

## Available Plugins

| Plugin | Description |
|--------|-------------|
| [android-claude-plugin](https://github.com/pcha/android-claude-plugin) | Skills and commands for Android development with clean architecture, MVVM, DI, and testing |
